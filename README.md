# 📖 Tiếng Việt

## ✨ Tính năng

| Chức năng | Mô tả |
|-----------|-------|
| 👤 Thêm bạn bè | Tự động gửi lời mời kết bạn từ trang Gợi ý |
| ❌ Hủy lời mời đã gửi | Hủy lời mời kết bạn đã gửi |
| ✅ Xác nhận lời mời | Chấp nhận lời mời kết bạn |
| 🗑️ Xóa lời mời | Từ chối lời mời kết bạn |

## 📋 Cách sử dụng

### Cách 1: Dùng Tampermonkey/Violentmonkey (Khuyên dùng)

1. Cài đặt extension **Tampermonkey** hoặc **Violentmonkey** trên trình duyệt
2. Tạo script mới và dán toàn bộ nội dung file `addbanbe.js` vào
3. Lưu lại
4. Vào Facebook và click nút tròn ở góc phải để mở menu
5. Chọn chức năng và nhấn "Bắt đầu"

### Cách 2: Chạy trực tiếp trên Console

1. Vào Facebook
2. Nhấn `F12` để mở Developer Tools
3. Vào tab **Console**
4. Dán toàn bộ code từ `addbanbe.js` vào console
5. Nhấn `Enter`
6. Click nút tròn ở góc phải để bắt đầu

## 🎯 Hướng dẫn từng chế độ

### 👤 Thêm bạn bè
- Vào trang **Gợi ý kết bạn** (facebook.com/friends/requests/)
- Chọn chế độ "Thêm bạn bè"
- Nhập số lượng và khoảng cách thời gian
- Nhấn "Bắt đầu"

### ✅ Xác nhận lời mời
- Vào trang **Lời mời kết bạn** (facebook.com/friends/requests/)
- Chọn chế độ "Xác nhận lời mời"
- Nhấn "Bắt đầu"

### 🗑️ Xóa lời mời
- Vào trang **Lời mời kết bạn**
- Chọn chế độ "Xóa lời mời"
- Nhấn "Bắt đầu"

### ❌ Hủy lời mời đã gửi
- Vào trang **Lời mời đã gửi** (facebook.com/friends/requests/outgoing/)
- Chọn chế độ "Hủy lời mời đã gửi"
- Nhấn "Bắt đầu"

| Tham số | Mặc định | Mô tả |

- **Facebook có thể giới hạn** số lượng kết bạn/ngày. Nên dùng vừa phải.
- **Không lạm dụng** để tránh bị khóa tạm thời.
- Sử dụng **tài khoản ảo** hoặc tài khoản ít quan trọng để test.

## 📋 How to Use

### Method 1: Using Tampermonkey/Violentmonkey (Recommended)

1. Install **Tampermonkey** or **Violentmonkey** extension on your browser
2. Create a new script and paste the entire content of `addbanbe.js`
3. Save it
4. Go to Facebook and click the round button on the right to open the menu
5. Select a function and click "Bắt đầu" (Start)

### Method 2: Run Directly on Console

1. Go to Facebook
2. Press `F12` to open Developer Tools
3. Go to **Console** tab
4. Paste the entire code from `addbanbe.js` into the console
5. Press `Enter`
6. Click the round button on the right to start

## 🎯 Guide for Each Mode

### 👤 Add Friends
- Go to **Friend Suggestions** page (facebook.com/friends/requests/)
- Select "Thêm bạn bè" (Add Friends) mode
- Enter quantity and time interval
- Click "Bắt đầu" (Start)

### ✅ Confirm Requests
- Go to **Friend Requests** page (facebook.com/friends/requests/)
- Select "Xác nhận lời mời" (Confirm Requests) mode
- Click "Bắt đầu" (Start)

### 🗑️ Delete Requests
- Go to **Friend Requests** page
- Select "Xóa lời mời" (Delete Requests) mode
- Click "Bắt đầu" (Start)

### ❌ Cancel Sent Requests
- Go to **Sent Requests** page (facebook.com/friends/requests/outgoing/)
- Select "Hủy lời mời đã gửi" (Cancel Sent Requests) mode
- Click "Bắt đầu" (Start)

## ⚙️ Configuration

| Parameter | Default | Description |
|-----------|---------|-------------|
| Quantity | 50 | Number of operations to perform |
| Interval | 500ms | Wait time between operations |

- **Do not overuse** to avoid temporary account restrictions.
- Use **virtual accounts** or less important accounts for testing.
